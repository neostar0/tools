DRAG AND DROP .md FILES ONTO drop-md-file-here.cmd TO ALIGN THEIR TABLES.

Drop one or more .md files onto drop-md-file-here.cmd and press Enter.
The aligned result is written next to each source as
    <name>_YYYY-MMDD-HHMM.md
and the original file is left untouched.

To run it without dragging, type:
    drop-md-file-here.cmd file1.md file2.md

Exit codes: 0 = all files processed, 1 = a file failed, 2 = bad usage.
